# AutoAlpha 因子、未来函数与过拟合审计

审计日期：2026-07-16
审计范围：`runtime/autoalpha.sqlite3` 中 200 个因子、自动评价器、盲测评价器、人工回测、资本账本、
连续记忆和研究世代治理。当前服务在第 259 轮保持停止，审计未启动新迭代。

## 结论

1. 200 个已入库表达式中，没有发现显式未来算子、非正窗口、未知字段、语义无效表达式、因子 ID
   不一致或完全相同的表达式。
2. 旧评价链存在系统性执行时点泄漏：完整日终量价信号按当日收盘到下一收盘收益评价，实际无法在信号
   完整形成后按当日收盘成交。所有旧分数和旧冠军均不得继续作为 v6 晋级证据。
3. 85 个 `ACTIVE/ELIGIBLE` 因子统一改按下一开盘执行后，9 个夏普保留率低于 50%，35 个低于
   75%，82 个仍为正，未出现正夏普直接翻负。结果说明旧评分被普遍抬高，但并非所有信号都由未来信息
   产生。
4. 当前数据适合价格量研究，不适合现金资本账本。OHLC 是前复权价格，`vol` 是手，`amount` 是千元；
   旧资本账本却按未复权人民币价格、股数和元处理，导致股数、手续费、ADV、容量及交割单失真。
5. 当前数据没有历史 ST、上市退市、停牌、涨跌停可买卖方向、指数成分和 PIT 行业/自由流通市值。
   因此所有结果只能标记 `RESEARCH_ONLY`，不能视为机构生产回测。
6. 截至收尾，43 条人工研究暴露中 38 条与隐藏期重叠，共污染 18 个因子。污染不能通过更换
   generation ID 清零。
7. 系统尚无正式盲测记录。2025-2026 被人工反复查看过的因子，不能再把该区间称为真正隐藏样本。

## 执行时点反事实

统一比较区间为 2015-01-01 至 2024-12-31，组合构建、持有期和费用保持一致：

```text
旧协议：EOD(t) 信号 -> 假定 close(t) 成交 -> close(t+1) 计收益
新协议：EOD(t) 信号 -> open(t+1) 成交 -> open(t+2) 计收益
协议码：EOD_T__OPEN_T1_TO_OPEN_T2
```

当前四因子组合从旧协议夏普 4.039、简单年化 26.40% 降至新协议夏普 3.327、简单年化

## 第 80 轮因子

`Volume_to_120d_Mean_Ratio_Reversal`：

```text
-cs_zscore(winsorize_mad(vol / rolling_mean(vol, 120), 5))
```

- 表达式只访问当日及过去 119 个交易日，不含前视算子；
- 旧协议夏普 2.489，新协议夏普 1.435，保留率 57.7%；
- 与 `Volume_Ratio_CSRank_Reversal_120d` 在当前选股规则下产生同样的排名收益，属于经济意义上的
  重复搜索，应合并计入同一假设族和多重检验；
- 已有 9 次人工回测暴露，且涉及隐藏期，因此不能再使用 2025-2026 作为该因子的无污染盲测；
- 结论为 `RESEARCH_REEVALUATION_REQUIRED`，不是“确认未来函数”，也不是生产可用。

## 系统性过拟合来源

- LLM 数百轮自适应查看同一公开窗口的精确分数；
- generation 重置曾同时缩小 DSR、BH/FDR 和 PBO 的候选族规模；
- 相近成交量反转公式被当作独立假设，低估有效尝试次数；
- 旧连续记忆向 LLM 暴露精确夏普、收益和接受结果；
- 人工回测可反复覆盖原隐藏期；
- 当前 `non_st` 数据无法证明是历史逐日非 ST 股票池，存在幸存者与股票池定义偏差；
- 前复权价与原始成交额/成交量混用，价格乘成交量类经济解释和现金容量口径不稳定；
- 市场中性研究含不可直接实现的对称做空腿，不应与 A 股长多生产组合混为一谈。

## 已实施的封堵

- 自动评价、盲测和人工研究回测统一使用下一开盘因果收益；
- v6 门禁强制检查评价协议与收益约定，未知协议按过期证据处理；
- 旧冠军不再自动继承，全部因子在 v6 下显示为 `STALE_PROTOCOL`，须重新评价；
- 旧协议长期记忆只保留名称、因子族和表达式签名，精确绩效、接受状态及方向反馈被清除；
- DSR 试验数使用累计因子库规模，BH/FDR 与 PBO 使用跨 generation 的全部公开历史；
- 人工隐藏期污染改为跨 generation 永久生效；
- 当前前复权数据上的资本账本、容量和交割单 fail-closed；
- 数据元数据明确写入 `forward_adjusted`、`board_lot_100_shares`、`thousand_cny` 和
  `capital_ledger_ready=false`；
- 看板 API 公开返回执行数据口径与阻断原因。

## 后续生产要求

1. 导入未复权 OHLC、股数成交量、人民币成交额及公司行动，单独建立现金执行面板。
2. 建立逐日 PIT 股票池、ST、停牌、涨跌停买卖方向、上市退市、行业、指数成分和自由流通市值。
3. 重新定义从未被人工查看的隐藏区；已污染因子只能进入新的时间后推测试或纸面仿真。
4. 对 200 个旧因子在 v6 下批量重评；相似表达式按假设族合并试验数，不因名称不同获得新试验身份。
5. 只有通过下一开盘时点、walk-forward、累计多重检验、成本压力和 PIT 数据门禁后，才允许进入盲测。
