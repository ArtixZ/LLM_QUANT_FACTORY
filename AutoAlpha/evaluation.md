# AutoAlpha 评价宪法 v8

> 状态：人类锁定，`institutional_walkforward_v8_us_equity_long_only_primary`。
> 适用范围：US 股票截面因子发现、现有多因子组合增强、模拟盘与生产准入。
> 核心改变：IC 是预测诊断，不是研究目标；收盘后可知信号只能评价下一交易日开盘后的收益；
> 候选价值由其对现有组合的成本后边际贡献决定。

---

## 1. 评价目标

AutoAlpha 不再回答“哪个公式的 IC 最高”，而回答：

> 在严格 point-in-time、样本外、风险和交易约束下，把候选加入当前基准组合后，是否以可解释、
> 可重复、可承载的方式改善投资者最终获得的净收益、风险或容量？

评价对象必须是以下配对实验：

```text
control   = 当前批准因子库 + 当前组合构建器 + 当前执行模型
treatment = control + 候选因子（其余配置完全相同）
increment = treatment - control
```

任何只报告候选单因子表现、却不报告相对 control 增量的实验，不能进入批准流程。

## 2. 不再使用单一主分准入

生产研究采用顺序硬门禁，不用加权总分决定接受或拒绝。原因是总分允许不合理补偿，例如高 IC
补偿严重回撤、高毛收益补偿不可成交、单一年份暴利补偿长期失效。

准入顺序为：

```text
数据与语义
  -> 统计可信度
  -> 跨期与状态稳健性
  -> 组合边际价值
  -> 独立性与风险
  -> 交易与容量
  -> 隔离 holdout
  -> 模拟盘
  -> 人类生产审批
```

任何一道硬门禁失败，后续更好的指标不能抵消。失败候选保留完整证据和失败原因。

## 3. 指标优先级

### 3.1 一级：组合边际价值

这是候选存在的主要理由，全部使用 treatment 相对 control 的成本后结果：

- 增量净 IR / Sharpe；
- 增量年化超额收益；
- 最大回撤变化与恢复时间变化；
- treatment 相对 control 的收益/回撤效率变化；
- 下行波动、CVaR、最差月份和尾部情景变化；
- 选股、行业、风格、Beta、成本和残差归因；
- 不同风险预算下的边际效用；
- 对现有组合换手、集中度和容量的影响。

收益必须至少报告毛收益、显式费用、点差、冲击、机会成本和净收益。只有毛收益改善而净收益不改善，
视为无投资价值。

### 3.2 二级：统计可信度与稳健性

- purged/embargo walk-forward 的组合增量结果；
- 成本后净超额收益的 HAC 或 block-bootstrap 置信区间；
- Deflated Sharpe Ratio 与 CSCV/PBO；
- 按年份、牛熊、波动、流动性、规模和行业分段的增量结果；
- 正增量年份比例、最差年份和年度增量收益离散度；
- 参数邻域、随机扰动、成本倍数和执行延迟敏感性；
- 样本内到样本外退化率、最差 fold、最长失效期；
- 研究次数和候选族规模调整后的多重检验结论。

统计显著不等于经济显著。样本很大产生的微小正收益，若不足以覆盖成本、模型误差和运营复杂度，
仍应拒绝。

### 3.3 三级：交易、容量与风险

- 年换手、持有期、ADV 参与率、不可成交比例和延迟退出；
- 1 倍与压力成本下的净 IR，盈亏平衡成本倍数；
- 不同资金规模的容量曲线与容量拐点；
- 个股、行业、风格、Beta 和流动性主动暴露；
- 压力情景损失、拥挤度、持仓重叠与集中度；
- 回测成交与模拟/实盘成交的 TCA 偏差。

### 3.4 四级：预测诊断（包含 IC）

IC 用于理解信号，不再作为统一准入硬门槛：

- Rank IC、Pearson IC、HAC t-stat、hit rate 和 decay；
- 十分组单调性、Top-Bottom spread 与覆盖率；
- 条件 IC、行业/市值中性化后的 IC；
- 预测方向、拥挤区间和失效状态。

低 IC 不必然无效：低相关但稳定的风险对冲、容量改善、换手降低或尾部保护因子可能显著提升组合。
高 IC 也不必然有价值：收益可能来自不可交易小盘股、极端值、行业暴露或高冲击换手。

IC 只有在以下场景可成为专用硬门槛：策略产品明确以截面预测准确性为交付目标，且该门槛在实验开始前
冻结。即使如此，仍不能替代组合和交易门禁。

## 4. 机构准入门禁

具体阈值由 `config/research.toml` 版本化，以下项目不可缺失。

### Gate A：数据与语义

- 数据契约、PIT、动态股票池、快照 checksum 全部通过；
- 因子 DSL 时间语义、数据滞后和复杂度通过；
- 每个字段必须声明可用时点；日线 `open/high/low/close/vol/amount` 在本协议中均按收盘后可用；
- 收盘后形成的信号最早在下一交易日开盘成交，主收益区间为下一开盘到再下一开盘；
- 因子研究使用 IBKR `ADJUSTED_LAST`；资金账本使用 `TRADES` 拆股调整 OHLC、股数口径成交量和
  USD 成交额。股息调整研究价不得用于现金、股数、手续费、ADV、容量或交割单计算；
- 覆盖率达到下限，缺失率和覆盖率无异常漂移。

失败结论：`REJECTED`。

### Gate B：统计可信度

- 成本后增量净收益的 HAC/Bootstrap 结论达到预设置信度；
- 多重检验通过；
- DSR 概率达到下限；
- PBO 不超过上限。

检验对象优先是组合增量净收益，而不是 IC。失败结论：`REJECTED`。

### Gate C：稳健性

- 正增量 walk-forward folds 比例达到下限；
- 最差 fold、最差市场状态和最长失效期可接受；
- 参数邻域没有尖峰最优；
- 执行延迟与随机扰动后方向不反转。

失败结论：`REJECTED` 或在证据不足时 `RESEARCH`。

### Gate D：组合边际价值

- 增量净 IR 达到最小经济改善；
- 增量年化净收益非负并达到最低规模；
- 最大回撤恶化不超过风险预算；
- 两倍基准交易成本下仍保留非负净 IR；
- 收益归因不存在未批准的单一风险来源主导。

这是最重要的投资门禁。失败结论：`REJECTED`。

### Gate E：独立性与风险

- 与因子库高度相关时，必须证明更强的净组合增量、容量或尾部改善；
- 条件贡献、增量解释度和边际组合 IR 有结论；
- 行业、风格、Beta、个股集中和压力损失不越限；
- 经济假设、适用状态和失败模式已写入因子卡。

“相关性高”本身不是绝对拒绝理由；低成本替代、容量替代和风险替代可以保留，但不能重复占用风险预算。

### Gate F：交易与容量

- 年换手、ADV 参与率和不可成交比例不越限；
- 目标资金规模不超过容量结论；
- 盈亏平衡成本倍数留有安全边际；
- 无法卖出、部分成交和等待成本被完整计价。

失败结论：`REJECTED`。

### Gate G：隔离 holdout 与模拟盘

- holdout 只允许候选绑定、一次性、低频访问；
- holdout 结果不参与参数回调；
- 模拟盘达到最短观察期，方向、净 IR、换手、暴露和 TCA 与研究一致；
- 生产发布必须由人类审批，且从小资金比例开始。

### 4.1 协议迁移与可行性恢复

评价协议升级后，现有组合必须在新协议下重新计算；数据库中的旧版夏普、收益或稳健性指标只能作为
审计历史，不得继续充当 planner 的 control。若 incumbent 违反新增的绝对门禁，系统允许执行受控的
公开区迁移动作，避免要求单个新因子一次修复全部历史缺口。

迁移动作必须同时满足：

1. 不新增任何绝对门禁违规；
2. 每个尚未修复的违规均达到配置冻结的最小改善步长；
3. 年化收益牺牲不超过 2%，最大回撤和成本压力不恶化；
4. 组合稳定性、最差 walk-forward fold 或绝对违规距离得到可核验改善；
5. 因子相关性、容量和交易门禁仍然有效。

该机制不是门禁豁免。仍有绝对违规的版本仅标记为 `PUBLIC_FEASIBILITY_RECOVERY`，可以成为下一轮
公开研究的 control，但不得访问 holdout、不得消耗盲测预算、不得标记为 paper 或 production
批准。只有全部绝对公开门禁恢复后，冻结的组合才可进入 Gate G。

加权搜索必须覆盖低权重试探、较高确信权重和替换场景；替换时其余成员按现有权重同比缩放。每轮还
必须独立评估 REMOVE，避免只有新候选单因子合格时才允许清理旧因子。

## 5. 候选之间如何比较

只有通过相同硬门禁的候选才允许互相排序。排序采用 Pareto 分层：

```text
越高越好：增量净 IR、增量净收益、回撤改善、容量
越低越好：换手、压力损失、复杂度、数据依赖、与现有组合重叠
```

若候选 A 在所有维度不差于 B，且至少一个维度更好，则 A 支配 B。先比较 Pareto 层级；同层仍无法
区分时，依次优先：回撤约束合规、增量净 IR、容量、简洁性。不得临时调权重让偏好候选获胜。

效果接近时，优先选择：

1. 经济机制更清楚；
2. 数据滞后和修订风险更低；
3. 参数更少、表达式更简单；
4. 换手更低、容量更高；
5. 与现有生产链依赖更少。

## 6. 标签与持有期

- 标签用于预测诊断，不直接决定投资价值；
- 收盘后信号的研究标签统一为 `EOD_T__OPEN_T1_TO_OPEN_T2`，不得使用当日收盘到下一收盘；
- 主投资评价使用下一交易日开盘成交后的逐日持仓净收益；若没有可验证的开盘成交条件则不产生评价；
- H 必须同时冻结信号形成、标签、组合重平衡和退出语义；
- 报告 H ∈ `{1, 3, 5, 10, 20}` 的 decay，但不从中事后挑选最好 H；
- 选择 H 属于候选搜索预算，必须计入多重检验。

## 7. Control、基准和成本

- control 是当前批准组合，不是空组合或等权 Top 10%；
- 基准由产品模板确定：长多、指数增强、市场中性分别使用对应基准；
- control 与 treatment 必须使用同一风险模型、优化器、约束和执行模型；
- US 股票每股佣金、最低佣金、SEC Section 31、FINRA TAF、整数股、停牌、ADV、点差和冲击全部计入；
- 至少报告基准成本、两倍成本和一日执行延迟三种情景。

## 8. 数据切分与反馈

- train：拟合参数与形成假设；
- validation：walk-forward 候选研究与门禁；
- holdout/test：仅用于受控泛化复核；
- test 不返回逐期明细给 Researcher，只返回批准所需的分级结论；
- test 失败后不得针对失败细节修改同一候选，必须开启新世代并消耗新预算。

### 8.1 当前冻结协议

- 探索区：2010-01-04 至 2017-12-29，可向 Researcher 返回完整公开诊断；
- 公开滚动区：5 年历史接 1 年验证，年度折从 2015 滚动至 2024；
- 隐藏区：2025-01-02 至 2026-07-14，仅可信评估边界可读取；
- 隐藏反馈：只允许分级结论和证据哈希，不返回收益、夏普、回撤或逐期明细；
- 研究组合：下一开盘执行、5 日错层持有与显式费用；100 万 USD 现金资本账本仅在严格 PIT
  执行数据口径通过后启用；
- 当前世代最多 500 个候选、每因子族 100 个候选、最多 10 次一次性盲测。
- 当前协议版本：`institutional_walkforward_v8_us_equity_long_only_primary`；协议变化自动封存此前仍为 ACTIVE 的研究世代。
- 单因子诊断不再把“相对零收益 control 的回撤”称为增量回撤；增量门禁只用于真实组合 control。

### 8.2 自适应方向微战役

系统不得逐轮追逐最近最高夏普。每次方向选择由确定性诊断器完成，只读取当前组合在本协议下的公开
重估、最近 24 个公开候选的失败类别以及冻结门禁，不读取 holdout、资本审批或生产结果。

可选方向为跨期稳定性、尾部风险、交易效率、稳健收益、可交易广度、因子库分散化和新机制探索。
诊断优先处理当前组合的绝对门禁缺口，其次聚合近期失败类型；方向一旦选定即冻结为微战役：

1. 每个战役最多提出 3 个候选，模型修复、执行失败和服务中断均消耗次数；
2. 连续 2 次没有形成该方向上的公开组合改善时提前停止；
3. 公开目标完全修复时可提前成功结束；
4. 已结束方向在随后 2 个战役内冷却，不得因“接近门槛”延长预算；
5. 每次方向、基线、依据、尝试和结束原因进入持久账本及哈希审计链；
6. 隐藏区结论不参与方向选择或战役成败，失败后不得沿同方向继续微调。

方向改善必须来自实际通过公开动作门禁的 ADD、REPLACE 或 REMOVE。单因子指标变好、最佳近失方案
变好或文字解释更充分都不算战役前进。

### 8.3 因子库与人工回测隔离

自动组合未采纳候选不等于因子永久失效。所有完成确定性评价的唯一因子都进入持久因子库，并按
经济机制归类为冠军、合格候选或观察因子。`SCREENED_OUT` 只表示该次自动准入失败，不得删除其
表达式、假设、评价证据或未来人工组合研究资格。

因子库可提供面向人工检索的相对排行榜。排行榜必须同时使用收益质量、滚动稳健性、风险、交易
效率和信息诊断；它只用于发现和排序，不参与自动准入，不能补偿任何硬门禁失败。

人工自选因子、权重和日期的回测统一标记为 `MANUAL_NON_GOVERNANCE`：

1. 结果不得更新冠军组合、因子状态、LLM 连续记忆或自适应方向；
2. 不消耗或解锁 holdout 预算，不作为自动晋级证据；
3. 请求、数据指纹、成本、净值曲线、指标、制品路径和结果哈希必须进入审计；
4. 人工回测可以与只读研究并行，但数据发布必须独占，且两者的状态与证据不得混写；
5. 人工查看隐藏日期属于人类事后研究，之后不得把精确结果反馈给同一自动研究世代。

公开滚动区在被多轮查看后属于自适应研究数据，不再宣称是 untouched OOS。只有隐藏区能够承担
泛化复核职责；即使隐藏区通过，资本残仓、敞口、费用或回撤门禁失败仍不得晋级。

固定日期、embargo、数据 checksum、成本与门槛均进入研究协议指纹。

## 9. 报告最小集合

每个候选报告必须包含：

| 证据组 | 必需内容 |
|---|---|
| 数据 | 快照、PIT、覆盖率、缺失、股票池变化 |
| 预测诊断 | IC、IC decay、分组收益、条件 IC |
| 组合增量 | 净 IR、净收益、回撤、CVaR、恢复期、归因 |
| 稳健性 | folds、年份、状态、参数邻域、延迟和扰动 |
| 统计 | HAC/Bootstrap、DSR、PBO、多重检验、实验次数 |
| 风险 | 行业、风格、Beta、集中度、压力情景 |
| 交易 | 换手、费用、点差、冲击、未成交、容量、TCA |
| 治理 | parent、模型、提示词哈希、审批、失败原因、owner |

不得只展示最好的年份、参数、资金规模或成本假设。

## 10. 决策状态

合法结论只有：

- `REJECTED`：硬门禁失败，保留墓地和冷却期；
- `RESEARCH`：方向有价值但证据尚不足；
- `APPROVED_FOR_PAPER`：研究与 holdout 通过，进入模拟盘；
- `APPROVED_FOR_PRODUCTION`：模拟盘和人类审批通过；
- `SUSPENDED`：生产漂移或运营异常，停止新增风险；
- `RETIRED`：经济机制、容量或稳定性永久失效。

## 11. 自动研究决策协议

生产系统不得计算、存储或比较候选总分，也不提供旧评分入口。自动决策只能由以下组件组成：

1. Executor 生成完整 `CandidateEvidence`，缺失或非有限值直接失败；
2. `build_evaluation_matrix` 将证据按组合、统计、风险交易和预测诊断分区；
3. `InstitutionalAdmission` 按固定顺序执行硬门禁，停止于首个失败门禁；
4. 实验账本记录门禁结论和失败原因，不记录父分数或分数增量；
5. 同一门禁层级内的批量候选使用 Pareto 非支配排序，不压缩为标量；
6. holdout、模拟盘和人类风险审批不允许由自动排序绕过。

LLM 只能收到受控失败类别和批准公开的诊断，不得获取可用于反向拟合 holdout 或门槛的明细。

## 12. 变更治理

修改门槛、比较顺序、control、成本、切分或 holdout 规则，必须：

1. 创建新评价版本和研究世代；
2. 记录变更理由与预期影响；
3. 不用旧 test 结果反向设计新规则；
4. 重新生成协议指纹；
5. 由研究与风险负责人共同审批。
