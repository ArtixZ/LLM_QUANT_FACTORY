系统接收可版本化的市场数据，让 LLM 负责提出假设、解释机制、设计证伪和诊断失败；公式执行、回测、统计检验、交易约束、盲测与发布结论由确定性组件完成。

04 · AUTOALPHA

AutoAlpha：任务化的自动因子研究

每个任务拥有独立市场、数据路径、可见时间、研究世代、预算、连续记忆与来源标签。

任务总表
任务协议

冻结“研究看得见什么”

  • 市场与数据工作区
  • 探索、公开验证和隐藏测试区
  • 因子数、轮次与研究世代预算
  • 协议指纹和数据快照指纹
候选生成

从经济机制到类型化表达式

  • 只使用数据契约允许的字段
  • 表达式经过算子、复杂度和时间语义校验
  • 方向微战役最多有限次尝试
  • 同方向失败后冷却并切换机制
评价循环

候选不是只和自己比较

  • 单因子预测和纯多表现诊断
  • 相对当前 control 的 ADD / REMOVE / REPLACE
  • 收益改善与风险改善双通道
  • 公开失败进入结构化根因记忆
资产沉淀

不当冠军也不被一票删除

  • 完成评价的唯一候选进入因子库
  • 保留公式、来源任务与迭代轮次
  • 记录相似簇、机制标签和生命周期
  • 后续可重评、组合研究或退役

04 · CAPITAL资金仿真区

交易限制、费用、冲击、容量与现金账本下的最终回放。

数据与语义统计可信度跨期稳健性组合边际价值风险独立性交易与容量盲测与模拟
一级组合边际价值

增量净 IR、增量年化、回撤改善、尾部风险、容量与成本后贡献。

二级统计与稳健性

Walk-forward、HAC / Bootstrap、DSR、FDR、PBO、参数邻域和状态稳定。

三级交易、容量与风险

换手、ADV 参与率、不可成交、成本压力、暴露、集中度和 TCA。

四级预测诊断

Rank IC、Pearson IC、衰减、分组单调性与覆盖率，用于解释而非补偿硬失败。

滚动样本外

避免把单个固定验证期逐轮训练成新的样本内。

隐藏评价器

不向 LLM 暴露隐藏夏普、收益、回撤或逐期路径。

多重检验修正

按候选族和尝试次数计入 FDR、DSR 与 PBO。

方向预算与冷却

同一优化方向只允许有限试探，连续失败强制换机制。

人工暴露台账

手动查看隐藏区会污染该世代证据并阻断盲测。

参数邻域检验

要求邻近参数仍有稳定表现，不接受孤立尖峰最优。

09 · AUTOCOMBINE

AutoCombine：受约束的多因子组合与权重研究

从 AutoAlpha 因子库冻结可见快照，在明确因子数量、权重、目标和时间协议内搜索组合。

组合任务
任务输入
  • 可见因子或手动指定因子
  • 必选因子与最大因子数
  • 最小/最大非负权重与步长
  • 探索、验证和隐藏区间
  • 目标预设与实验预算
搜索与评价LLM 子集假设确定性权重邻域稳健性门禁Pareto 前沿
任务输出
  • 每次实验的子集与最终权重
  • 公开指标轨迹与失败门禁
  • 成本和回撤稳健性证据
  • 盲测分类与证据哈希
  • 不可变 StrategySpec 版本
默认降低回撤优先

在基本收益约束下优先改善最大回撤、尾部风险和最差折。

可选组合夏普优先

强调成本后风险调整收益，同时保留回撤、换手和稳健硬门禁。

可选年化收益优先

提高净年化，但不允许用收益补偿不可交易、过度集中或盲测失败。

可选均衡稳健

在增量收益、回撤、最差折、换手和机制分散之间做 Pareto 选择。

任务运行中因子快照不漂移。因子方向继承自 AutoAlpha，LLM 不能引用快照外因子、翻转方向、查看隐藏精确指标或绕过确定性约束。
